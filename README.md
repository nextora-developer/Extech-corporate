# Extech Studio — Corporate Website

Official corporate website for **Extech Studio**, a digital engineering studio focused on building scalable web systems, e-commerce infrastructure, and high-performance digital products.

This repository contains the **static corporate website** (non-Laravel), designed with a modern, dark, technology-driven aesthetic.

---

## 🧠 About Extech Studio

Extech Studio is a technology-first digital studio that designs and engineers systems — not just websites.

We focus on:

- Clean architecture
- Scalable infrastructure
- Automation-ready systems
- Long-term maintainability

This corporate site serves as an overview of our capabilities, approach, and studio philosophy.

---

## 🌐 Website Pages

- **Home** — Studio overview & value proposition
- **About Us** — Studio mindset, principles, and direction
- **Our Services** — What we build & how we help
- **Portfolio** — Selected projects & case previews
- **Contact** — Project inquiries & consultations

---

## 🛠 Tech Stack

This website is intentionally kept **simple, fast, and dependency-light**.

- **HTML5**
- **Tailwind CSS (CDN)**
- **Custom CSS**
- **Google Fonts**
  - Inter
  - JetBrains Mono
- **Vanilla JavaScript**

No frameworks. No backend. No build pipeline.

---

## 🎨 Design Direction

- Dark, minimal, technology-focused UI
- Subtle grid backgrounds & soft glows
- Clean typography with strong hierarchy
- Mobile-first, responsive layout
- Studio / engineering aesthetic (not marketing-heavy)
